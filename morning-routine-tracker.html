Morning Routine Tracker

A complete hardware + software solution — an Arduino device with thermal printer connected to a live web app — that guides children with ADHD through their morning routine one task at a time.

Software App & Hardware Device

The morning routine tracker comes in two forms. Use the web app right now on any phone, or connect to the physical Arduino device for a full hardware experience.

Hardware — Arduino Device

Physical push-button tracker

An Arduino Uno-based device in a portable white enclosure. The child presses a physical button to mark each task as done. RGB LEDs provide visual feedback, the LCD shows the next task, and on 100% completion the thermal printer outputs a reward slip with the child's name.

ControllerArduino Uno + NodeMCU ESP8266
Input5 push buttons — one per task
FeedbackLCD display + RGB LEDs (task-by-task)
RewardThermal printer — personalised sticker via Bluetooth
ConnectivityBluetooth to companion web app

How the App & Device Work Together

1. Set Up on the App

Parent enters the child's name, adds tasks, and records a voice message for each one on the web app.

2. Child Completes Tasks

Child taps the app card or presses the hardware button after each task. Sequential lock prevents skipping.

3. Voice Message Plays

After completing a task, the custom voice message plays automatically — a motivational or instructional cue from the parent.

4. All Done — Reward!

Confetti burst, congratulations screen, and a personalised thermal reward sticker prints via Bluetooth — a tangible reward the child can keep.

ADHD-Informed Design

Why This Works for Children with ADHD

Sequential Unlocking

Only the current task is active. Children can't jump ahead, which removes the overwhelm of seeing the whole list at once.

Immediate Positive Reinforcement

Confetti, motivational toasts, voice messages, and a printed sticker provide immediate, tangible rewards — which are more effective for ADHD brains than delayed praise.

Multi-Sensory Cues

Visual (progress bar, coloured cards), auditory (voice messages, TTS), and tactile (hardware button press, printed slip) cues engage multiple senses — reinforcing task completion.

Consistent Routine

Same tasks, same order, every morning. Consistency is key for ADHD — removing the need to decide "what's next" reduces cognitive load.

Reduces Parental Reminders

The app/device does the reminding — parents don't need to nag, which reduces family conflict and stress during morning routines.

Privacy Safe

All data stored only on the device — no accounts, no cloud, no data leaving the family's hands. 100% free to use.
